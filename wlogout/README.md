# wlogout theme

Custom theme for **wlogout**, the graphical power menu that complements
Wayland compositors.

Folder contents:

* `layout`        – XML layout used by wlogout to position the buttons.
* `style.css`     – Catppuccin flavoured styling.  A `.bak` backup is kept.
* `icons/`        – SVG icons for shutdown, reboot, suspend, etc.

Copy the folder into `~/.config/wlogout` and invoke `wlogout` to test the
layout.
