# Tofi launcher configuration

Configuration snippets for **tofi**, a lightning-fast Wayland application
launcher that aims to be a modern replacement for rofi/dmenu.

There are three presets which I switch between, each stored in its own file:

* `config`   – default look: centred, semi-transparent, 30-pixel border.
* `configA`  – alternative layout for small laptop screens.
* `configV`  – vertical list variant inspired by dmenu.

Link one of these files as `~/.config/tofi/config` depending on the desired
layout.  All presets share the same Catppuccin-Mocha colour palette for visual
consistency with the rest of the desktop.
