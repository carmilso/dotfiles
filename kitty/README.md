# Kitty terminal configuration

Configuration for the **kitty** GPU-accelerated terminal emulator.

Files of interest:

* `kitty/.config/kitty/kitty.conf`   – main configuration file.
* `Catppuccin-Mocha.conf`, `OneDark-Pro.conf` – colour themes.
* `current-theme.conf`              – symlink / include that selects the
  active theme.

Quality-of-life tweaks:

* Custom font stack using JetBrainsMono Nerd Font.
* Transparent background and adjustable padding.
* Clipboard-friendly shortcuts (⌃+Shift+c / ⌃+Shift+v).

Copy or symlink the `kitty/.config/kitty` directory into `~/.config` to start
using the configuration.
